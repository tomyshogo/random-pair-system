# 音源ファイル

このフォルダに以下の音源ファイルを配置してください：

## 必要なファイル

1. **bgm.mp3** - BGM（クリスマスソング）
   - ループ再生されるBGM
   - 推奨：クリスマス関連のBGM、長めの楽曲

2. **tick.mp3** - ルーレット回転音（ベル音）
   - ルーレットが回転している時の効果音
   - 推奨：短いベル音やチック音

3. **feint.mp3** - フェイント音（「あれ？」）
   - フェイント時の効果音
   - 推奨：短い疑問符的な音

4. **grab.mp3** - つまむ時の音（キラーン）
   - 名前をつまみ出す時の効果音
   - 推奨：キラーンという感じの音

5. **fanfare.mp3** - 決定時のファンファーレ
   - ペアが決定した時の効果音
   - 推奨：ファンファーレや成功音

6. **applause.mp3** - 拍手歓声
   - 全ペア決定時の効果音
   - 推奨：拍手や歓声

7. **jingle.mp3** - ジングルベル
   - ルーレット回転時のジングル音
   - 推奨：ジングルベルやクリスマス関連の音

## フリー音源サイト

以下のサイトから無料の音源をダウンロードできます：

- **Pixabay** (https://pixabay.com/music/)
- **Freesound** (https://freesound.org/)
- **Zapsplat** (https://www.zapsplat.com/)
- **Incompetech** (https://incompetech.com/music/royalty-free/)

## 注意事項

- ファイル形式は **MP3** を推奨します
- ファイル名は上記の通りにしてください（大文字小文字を区別します）
- 音源ファイルがない場合でも、アプリは動作しますが音声は再生されません
